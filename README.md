# SYSTEM MAP — WSL2

The Haus, by name: every planet (repository), where it stands, which
division holds it, and who sits there. One file, regenerated by hand
when a planet lands or a seat is stood up. A map, not a transcript:
what a seat *is* lives in its own Instruktion — this file gets you to
the door.

## How to read this

Don't read it whole. **Scan** — the name index or the table finds the
planet. **Jump** — that planet's section below carries the ground in
one line and every seat in one line. **Open** — the seat's Instruktion
at `<location>/.claude/agents/<name>.md` carries the depth; its
`description:` frontmatter is the authoritative one-liner (`head -12`
is enough).

## Conventions

- **Location:** `~/repos/<planet>`. One exception: `C:\GTypeEquipment`
  (the bus) stays on Windows — `/mnt/c/GTypeEquipment` from WSL,
  read-only; written only through the Munitionsaufzug (the hoist).
- **Agents:** Claude identities are at `<location>/.claude/agents/<name>.md`;
  native Codex identities are in that ground's `.codex/config.toml`.
  Open a seat on its own ground. Cross-ground work uses `bm-correspondence`:
  a drop at `~/repos/Ark/Poststelle/`, assignment and state in its Gehirn.
  The Operator is never the courier; foreign mailrooms and queue dispatch
  are retired. Local queues stay with their owning seats.
- **`pending`** = not yet cloned to WSL; the location is where it
  will stand.
- **Divisions:** CENTCOM · Tactical · Technical · Science · S.C. ·
  Sigma · Tragwerk · EXEC. `?` = not yet assigned.
